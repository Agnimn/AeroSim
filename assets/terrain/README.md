# Local terrain data

`test_heightmap.png` is a 129 × 129, 8-bit grayscale image generated by `tools/generate_test_heightmap.py`. Bright pixels encode higher elevations; dark pixels encode lower elevations. It is a synthetic prototype and does not represent real geographic or elevation data.

The image is embedded by CMake and loaded offline by Qt Quick 3D `HeightFieldGeometry` from `qrc:/AeroSim/assets/terrain/test_heightmap.png`. Re-run CMake configuration after changing/replacing the image.

To regenerate it, run the script with Python 3.12 or newer; it only uses the standard library.

## Importing a real North India DEM

No real DEM is included in this repository. Obtain a legally licensed DEM such as Copernicus DEM GLO-30 or SRTM for the selected test region before importing it. Copernicus DEM uses WGS84 horizontal coordinates and EGM2008 heights in meters; verify the metadata of the downloaded product before choosing `--vertical-datum`. SRTM products commonly use WGS84 horizontal coordinates and EGM96-referenced heights in meters.

The reproducible importer requires Python packages `rasterio` and `numpy`:

```text
python tools/import_dem.py path/to/licensed_dem.tif --vertical-datum EGM2008
```

It reprojects the input to EPSG:4326, clips/resamples the North India test bounds, writes `north_india_dem.png` and `north_india_dem.json`, and records the source CRS, vertical datum, elevation range, dimensions, and WGS84 bounds. The generated files remain local and are conditionally embedded by CMake after reconfiguration.

Until both generated files are present and valid, the 3D view explicitly reports `SYNTHETIC TEST SURFACE`; it does not claim that real terrain is loaded.
